# 运行机制与协议

## 两种运行模式

同一个静态 Go 可执行程序有两种模式：

- 入口：`scf-tunnel -config /path/agent.json`，处理电脑的 HTTP/CONNECT/SOCKS5 请求。
- 节点：`scf-tunnel -node`，读取 `CLOUD_PROXY_TOKEN` 环境变量，在 SCF 容器内监听 `:9000`。

WSS 的公网 TLS 由函数 URL 平台承接。代码自身的节点监听是容器内部 HTTP/WebSocket，不是一个可以直接公开任意 TCP 端口的 SOCKS5 服务。

## 一次新建连接的状态机

1. 入口完成用户认证；SOCKS5 通过 RFC1929，HTTP 通过 Proxy-Authorization Basic。
2. 已知私网、回环、链路本地 IP 快速拒绝；已失败目标的 15 秒退避尚未结束时不调用 SCF。
3. 申请并发槽位，最多等 5 秒；为一次云调用申请小额费用预留。
4. 轮询选择一个不在冷却中的区域，通过 WSS `/tunnel` 发送以下连接元数据：

   ```text
   X-Tunnel-Token: <共享随机令牌>
   X-Tunnel-Target: <目标域名或IP>:<端口>
   X-Tunnel-Protocol: 2
   ```

5. 节点校验令牌并升级为 WebSocket，解析目标域名，过滤非公网地址并尝试 TCP 建连。
6. 节点发送第一条文本消息，成功为 `{"ok":true}`；失败为 `{"ok":false,"error":"target","detail":"..."}`。
7. 只有收到成功确认后，入口才向电脑报告 CONNECT/SOCKS5 成功。
8. 此后只传输二进制字节，不解释目标 TLS。正常单方向 EOF 使用文本控制消息 `EOF`，以保留 TCP 半关闭。
9. 所有方向结束或发生错误/限制时关闭隧道，释放槽位并结算预留。

节点保留了对无版本头的旧入口的兼容路径，便于先更新云端再更新入口。旧路径在目标错误时仍可能受 SCF 握手错误改写影响，因此新入口始终使用协议 2。

## HTTP 与 SOCKS5

### HTTPS / CONNECT

入口收到 `CONNECT host:port` 后建立云隧道；成功才返回 `200 Connection Established`。之后浏览器和目标网站自行完成 TLS 握手。原始域名、网站证书和应用数据通过隧道，不签发代理证书。

### 普通 HTTP

HTTP Transport 通过同一云隧道建立到目标的 TCP 连接，转发 HTTP 请求，移除 hop-by-hop 和代理认证头。目标 keep-alive 连接可能被复用，不是每个请求重新选节点。

### SOCKS5

只启用账号密码认证；域名由云端解析。入口本地不把域名提前替换为 IP，避免破坏目标域名语义。支持 TCP CONNECT，不实现 BIND 和 UDP ASSOCIATE。

## 三类失败分别处理

| 类型 | 典型情况 | 行为 |
|---|---|---|
| 目标错误 | DNS 不存在、目标拒绝、目标 TCP 超时 | 不增加区域故障计数；最多尝试两个不同区域，全部为目标失败则按该地址退避 15 秒 |
| 节点 / 通道错误 | WSS 建立失败、确认读取失败、平台异常 | 区域故障计数增加，连续 3 次后冷却 30 秒；成功恢复计数 |
| 本地拒绝 | 私网、预算、并发不足、进程停止 | 在本地返回错误，不据此停用区域 |

区域成功会清除其连续故障。已经建立的隧道发生故障时不切换区域、不重放应用写入，以避免重复提交或破坏 TLS/TCP 状态。

## 流量与会话生命周期

`stream.go` 将 WebSocket 消息包装为 `net.Conn` 风格字节流。单次分片 16KiB，两个发送方向各自至少间隔 150ms，低于参考平台默认的帧率和单连接请求速率边界。

当前上限为 2 小时、空闲 120 秒、上下行合计 128MiB。平台还可能因配额、资源、升级、网络或自身限制提前结束连接。**EOF 后另一方向仍可继续发送**；无后续数据时最终由空闲限制回收，客户端关闭并不代表所有半关闭连接会立即释放。

并发槽位同时计算正在建立和已经建立的隧道。页面上多个站点、DNS over HTTPS、后台应用都可能占用槽位，不应把单次请求测试当作真实浏览器并发验证。

## 小额滚动预算

`meter.go` 仅用于本地保守估算，不是云账单 API。

- 使用 128MB 参考计算费、调用费和保守的双倍流量估算。
- 每次调用先预留 30 秒计算加 256KiB 流量及初始化余量，而不是整个 2 小时/128MiB 的最大成本。
- 字节收发前及入口每 5 秒检查时计算估算进度；预留剩余不足半个窗口时再补充。
- 补充超过月阈值时关闭当前隧道，新的隧道也会被拒绝。
- 费用写入临时文件后原子替换账本；正常关闭结算实际观察到的时长/字节，异常退出留下保守预留。
- 北京时间跨月时，对仍活跃的连接保守延续估算。多进程不能同时写一个账本。

价格不是实时拉取，部署、绕过入口的云调用、账号其他资源等不完全包含在模型中。调整云函数内存、价格、区域、计费方式或用途后，应重新评估模型和余量。

## 不提供的保证

不提供固定可选公网 IP、不保证每条连接使用不同 IP、不提供连接迁移、不提供 UDP、不保证所有外网目标都可达，也不提供跨服务器的高可用。自动重启只恢复代理进程，原会话需要客户端重新建立。
