# AI Agent 授权渗透测试接入

## 工作边界

本项目为 AI Agent 的执行器提供 HTTP CONNECT / SOCKS5 TCP 出口。适合已授权的 Web/API 请求验证、浏览器访问及支持该代理协议的 TCP 工具。

执行器负责确定目标、验证授权范围、设置目标 QPS/并发、约束重试和收集测试证据。项目没有内置目标白名单、漏洞扫描引擎或按任务隔离的审计系统；不能把“能通过代理连接”解释为目标获得授权。

当前只部署大陆区域时，部分外网目标仍可能无法连接。区域轮询也不保证每次得到独立 IP，不提供固定出口清单。

## 凭据注入

运行入口程序需要自己的私有 `agent.json`；运行测试的执行器只需要代理地址及代理账号，不需要腾讯云管理密钥或节点令牌。

推荐在执行器的 Secret/环境变量中注入 `SCF_PROXY_URL`，例如其值可以是带正确 URL 编码账号密码的 HTTP 代理 URL。不要把真实值放在提示词、仓库、CI 日志或工具命令回显中。含 `@`、`:` 等字符的账号密码必须正确 URL 编码。

代理入口的账号认证传输本身没有 TLS，应通过可信内网或 VPN 访问。目标为 HTTPS 时，客户端与目标网站的 TLS 端到端保持，继续验证网站真实证书，不使用 `verify=False`、`-k` 或代理私有 CA。

## HTTP 客户端接入

### curl

执行器预先设置私有 `SCF_PROXY_URL`，并在校验目标属于授权范围后设置 `TARGET_URL`：

```bash
# 两个变量由执行器注入，不要打开 shell 的 set -x。
curl --noproxy '' --proxy "$SCF_PROXY_URL" \
  --connect-timeout 10 --max-time 30 "$TARGET_URL"
```

如果同一执行器中多个工具都明确支持环境变量代理，也可分别设置 `HTTP_PROXY`、`HTTPS_PROXY`。不同工具对大小写、NO_PROXY 和 SOCKS 的支持不同，应实际验证；不要依赖环境变量拦截本不支持代理的工具。

### Python requests

以下示例由执行器提供两个环境变量，代码不回显代理凭据。示例本身不实现授权范围校验，调用前必须在执行器中完成。

```python
import os
import requests

proxy = os.environ["SCF_PROXY_URL"]
target = os.environ["TARGET_URL"]  # 执行器已经校验的目标

with requests.Session() as session:
    session.trust_env = False
    session.proxies = {"http": proxy, "https": proxy}
    response = session.get(target, timeout=(10, 30))
    response.raise_for_status()
    # 按测试任务需求处理 response；不要把认证 Cookie 等敏感内容无差别写入报告。
```

`requests` 是执行器示例依赖，不是云节点运行依赖。Session 会复用 TCP/TLS 连接，复用期间出口保持一致。要观察新连接轮询，应建立新的 TCP 会话，而不是假设同一 Session 每次 GET 都换 IP。

## 浏览器与支持 SOCKS5 的工具

可让浏览器通过标准代理参数接入，或在 Proxifier 中为指定应用配置 `10801 / SOCKS Version 5` 和账号认证。也可对支持 CONNECT 的工具使用 `10800`。

实际命令行参数以目标工具自身文档为准。某些工具的“代理”只覆盖 HTTP 模块，原始 TCP/SYN/UDP 模块并不会自动走代理；使用前需通过受控目标验证来源与协议路径。

内网、回环和链路本地地址会被拒绝。已授权内网测试需要使用客户端可达的 Direct 路径或单独设计的内网测试环境，不应把当前公网 SCF 出口当作内网跳板。

## 任务并发与重试

- 默认 32 个共享建连/活跃槽位，浏览器后台、DNS over HTTPS、多个 Agent 都会共同占用。
- Agent 的“4 个任务”可能产生远多于 4 条 TCP 连接；先测实际峰值，再决定配置。
- 单次新建连接最多尝试两个不同区域；已经建立的连接不自动重放应用数据。
- 目标重复失败会按地址退避 15 秒。执行器应识别失败原因并限制重试，避免反复验证一个本来不可达的地址。
- POST、状态修改操作及其他有副作用的测试，应由任务层判断是否可以重试，不能因为切换代理就盲目重发。
- 2 小时、空闲 2 分钟、128MiB 单连接上限、约100KiB/s 单方向节奏及平台自身限制仍然适用。

## 费用与任务记录

8 元默认本地阈值是共享估算保护，不是每个 Agent 的额度，也不是腾讯云账单的精确封顶。活跃连接会消耗计算时间；滚动预留避免按最大生命周期一次性占满预算，但并不免除费用。

任务执行器宜记录：任务 ID、授权目标、时间、使用的入口、目标状态、超时、应用重试和是否命中本地保护。代理自身日志包含目标主机/端口、区域及错误类型，没有记录完整请求/响应正文，也不具备跨 Agent 的完整任务追踪能力。

如需任务级费用隔离、独立并发配额或可独立停止的运行环境，使用不同入口实例和独立账本；不要让多个进程共享同一个账本文件。

## 不应作出的推断

- 新连接选了不同区域，不代表必定获得新 IP。
- 目标超时，不代表整个区域离线。
- 本地费用保护未触发，不代表腾讯云没有发生费用。
- HTTPS 不做 MITM，不代表普通 HTTP 或代理入口认证同样获得端到端加密。
- 仓库公开，不代表代码已经实现目标授权检查、无限连接或所有工具协议兼容。
